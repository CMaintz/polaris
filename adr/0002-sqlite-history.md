# ADR 0002 - SQLite Initial Persistence Decision

Status: Accepted historically; superseded for web deployment evaluation

## Decision

SQLite was selected as the initial persistence technology when Polaris was conceived as a local desktop application.

## Current interpretation

This decision is retained as project history but is not an instruction to force SQLite into the hosted web architecture.

The web implementation must resolve the database question explicitly. See `docs/12-open-decisions.md`.
